🔎 Simple Port Scanner

A basic Python port scanner created as a beginner cybersecurity project.

🛡️ About

This program allows the user to enter a target IP address and a range of ports to scan.

It uses Python’s built-in Socket library to attempt TCP connections and identify open ports.

🛠️ Built With

* Python
* Socket Library

⚙️ Features

* Enter a target IP address
* Choose a minimum and maximum port
* Scan a range of TCP ports
* Identify open ports

⚠️ Disclaimer

Only scan IP addresses and systems that you own or have explicit permission to test.

This project was created for educational purposes and cybersecurity learning.

🎯 Purpose

A simple beginner project to practice networking, sockets, and basic cybersecurity concepts.
